## 实现

- **协议连接**：完成 initialize / initialized 后再放行普通 RPC；校验 WebSocket 握手；连接与 RPC 有超时；优先复用正在运行的 daemon。超时写入结果保留为未确认，不自动重发。恢复会话使用 `excludeTurns: true`，发送前不再传输整段历史。模型完整读取所有分页，stdio 跨块 UTF-8 正确保留。
- **版本与路径兼容**：配置和 Desktop bridge 一致遵循 `CODEX_HOME`，各显式路径仍优先；`cloudex about` 按真实文件类型检查 Unix socket 和目录。原生 Plan 完整终态、reasoning 字符串内容和未知可选附件类型不再导致整页解码失败。
- **实时同步**：监测 sessions 和 session_index 文件变化，100 ms 合并触发项目快照；3 秒轮询继续兜底。事件头禁用代理缓冲，过慢客户端断开后重连核对历史。SSE 支持 CRLF、CR、LF、跨块 UTF-8 和多行 data，后台串行解析；旧重连回调不能覆盖新连接，心跳失联有超时和退避。Codex 连接断开时清除失效审批及输入请求。
- **快速读取**：历史摘要增量读取且不保留工具正文；四组并发限制大文件缓冲。文件按 256 KiB 读取，大单行只在完整时拼接，避免二次复制。最多缓存四份详情，来源大小预算 64 MiB，至少保留当前一份大历史，保证活跃长会话继续增量读取。标题索引变化单独更新，不必重读 rollout。
- **历史分页**：从 HTTP thread 元信息中移除重复的全量 turns，compact 响应保留真实 `hasMoreBefore` / `nextBefore`，Plan 仍属于可见最终回复和搜索结果。停止/引导任务从详情独立 turns 定位活动轮次，保留原有控制语义。
- **iOS 读写**：GET 超时 15 秒、POST 超时 45 秒，允许服务端 30 秒 RPC 超时先返回明确结果；不增加自动重复发送。URL 仅允许有效 HTTP(S) 地址。本地 compact 缓存继续保存过程附件。Plan 完成事件的权威文本允许替换更长的流式草稿。

## 真实大历史与恢复时序：第 10 版

这轮修复以实际运行问题为依据：项目首屏会等待可选接口；会话实时连接等待缓存和 HTTP 两条路径都完成；递归目录监听在真实 sessions 树静默失效；最近三轮响应仍包含 16.6 MB 内联图片；两个大历史切换导致缓存反复淘汰。Desktop 当前确实已接入共享桥接，不能继续套用第 8 版的独立后端前提。

- **首屏与路由**：项目列表先发布，可选审批/输入请求独立更新。保留当前可用地址，250 ms 后尝试备用 LAN/VPN 地址，取消输掉的 GET；POST 继续只尝试一次。缓存和 HTTP 任一先呈现内容后即可订阅，前台恢复时并行连接与核对历史。
- **实时与恢复**：当前、正在运行的会话采用 250 ms 文件元数据兜底，当前日期目录和索引/归档文件也持续检查，使没有选中聊天的首页能发现新会话。文件变化合并 100 ms 后直接通知对应聊天，再同步项目列表；3 秒全列表核对仍作为最后兜底。后台和导航切换取消旧读请求，空闲会话继续保留只读订阅。
- **重连与请求重叠**：SSE 游标包含控制服务实例 UUID，重连只重放缺失后缀；游标过期或服务重启时转为历史核对。历史请求进行中又有变化会保留一次待补读。逐 token 事件避免反复发布相同运行状态和逐事件创建 MainActor Task，既有 60 ms 渲染节流继续保留。
- **大历史与附件**：HTTP 先分页再转换媒体/合并审批。图片通过内容寻址文件缓存和已认证文件接口读取，聊天页与事件不再携带原始 base64；保留原图字节。iOS 缩略图在后台读写，磁盘上限 40 MB、内存上限 20 MB，支持已加载图片的离线重开。历史缓存按保留对象估算计量，最多四份、128 MiB，至少保留当前一份；实测大历史对约 119 MiB，原 64 MiB 确实不足。全局搜索最多两份历史并发读取，达到结果上限后停止安排后续读取。

## 子智能体父子关系与活动查看：第 11 版

实际 rollout 的 `source.subagent.thread_spawn` 含父会话、昵称、角色和路径；旧解析只识别字符串来源，并返回空父 ID。另一个已确认的实际原因是 `fork_turns=all` 子会话继承主会话历史，其中第二条 `session_meta` 覆盖了第一条子会话身份。本批修复以首次匹配文件线程 ID 的元数据为身份依据，保留继承的历史，但仅以子会话创建后的自身生命周期判断活动状态。

- **归属**：项目、独立会话列表和搜索使用同一主会话树；子智能体以 `subagents` 递归返回。普通 `forkedFromId` 仍是独立分叉；缺少可靠父关系的内部智能体和异常循环不冒充主会话。支持原生 `archived_sessions` 和父会话下已归档的子智能体，子详情可读取归档历史。
- **状态**：明确区分运行、完成、失败、中断、等待、准备、关闭和未知。`idle`、`notLoaded` 或过时运行记录不直接判成完成。父会话的 `SubAgentActivity`、`CollabAgentToolCall` 状态按时间证据合并；明确的 API 活动状态优先，普通活动完成不覆盖失败、中断或关停。API 列表完整分页并指定来源；没有本地证据的子会话通过缓存的最近一轮状态核对，`limit: 1 / itemsView: notLoaded` 不加载工具正文。
- **实时**：后代的身份、状态和修订参与主会话 SSE 快照。选中或订阅主会话时，其全部后代进入 250 ms 文件元数据观察，包含已完成、随后被再次启动的子智能体；未选中的活动子智能体也继续观察。
- **iOS**：主会话顶部显示子树头像组和状态计数，点开列表后查看子会话或更深子智能体。每个查看页复用既有分页、过程详情、缓存和 SSE，但持有独立只读模型；主会话草稿、选择和实时连接保留。子页面隐藏发送、队列、引导、分叉和审批/输入操作，同时在模型入口阻止写入。查看页不重复发布通知、小组件或全局偏好。列表和子详情都提供独立关闭按钮。升级后项目索引改用 v2 文件，避免旧版无父关系的平铺列表在离线恢复时复现；既有聊天历史缓存保留。
